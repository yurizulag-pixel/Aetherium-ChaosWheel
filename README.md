# Aetherium-ChaosWheel

Motor independiente de AETHERIUM para Paper 1.21.4, Java 21. No requiere mods cliente ni resource pack.

Comando: `/achaos`. Versión 0.1.0-alpha, requiere compilación y pruebas antes de producción.

La mecánica es reutilizable en el mundo normal. Aetherium-Minigames podrá integrarse mediante una API en una versión posterior.
